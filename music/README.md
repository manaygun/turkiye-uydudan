# Your own music (optional)

Put royalty-free tracks here and the Reels use them instead of the generated soundtrack.

- `music/<mood>/` is for one mood: calm, water, city, build, drama, mountain
- tracks directly in `music/` are used for any mood without its own folder

Formats: .mp3 .m4a .aac .wav. Each place gets the same track every time (picked by place name).
Only use music you're allowed to post, e.g. Pixabay Music (free for social media, no credit needed).
If a folder is empty, a Turkish-style track is generated automatically.
